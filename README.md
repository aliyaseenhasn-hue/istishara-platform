# استشارة | Istishara

منصة قانونية عراقية مبنية بـ Flutter وSupabase لربط طالبي الاستشارة بالمحامين وإدارة الحجوزات والتواصل والمدفوعات والإشعارات.

## الوثائق

- `PROJECT_MASTER_DOCUMENTATION.md` — التوثيق العام للمشروع.
- `PROJECT_AI_CONTEXT.md` — سياق العمل والقرارات المهمة للوكيل الهندسي.
- `DEVELOPER_SETUP_GUIDE.md` — إعداد بيئة التطوير.
- `docs/booking_lifecycle.md` — دورة حياة الحجز.
- `CHANGELOG.md` — سجل التغييرات والتدقيق التاريخي الموحد.

## البنية الأساسية

- Flutter: Android / iOS / Web-PWA.
- Supabase: Auth / PostgreSQL / Storage / Realtime / Edge Functions.
- الفرع الإنتاجي: `main`.
- Android package: `com.istishara.app`.

لا تحفظ المفاتيح السرية أو ملفات توقيع Android داخل المستودع.
